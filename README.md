# LinearRegression
Linear Regression model in python developed in jan2024 for determining students success in tests. We only took 1 variable, hours studied in 1 linear regression model. In another we inputed more variables and found that with more variables, the Mean Squared area is lower.Additonally, we found that adjusted R^2 was .99. This indicates that the linear regression model has a very success prediction rate on how well the students do on their tests.
